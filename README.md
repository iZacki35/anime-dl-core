## 🧩 Troubleshooting (If Things Go Wrong)

**Problem: "Link not supported" error**
- Make sure you copied the embed URL *inside* the player, not the whole page URL. Look for text starting with `https://` followed by something like `kodik.info/`, `aniboom.one/`, etc.

**Problem: Download is slow**
- Try a different video source if the site offers multiple players. Some are faster than others.

**Problem: Video won't play after downloading**
- Install VLC media player (free). It handles all formats that HLS, DASH, and MP4 create.

**Problem: "No stream found"**
- The episode might be region-locked or temporarily removed. Try a different episode or come back later.

**Still stuck?** Re-download the latest version from the link at the top—updates often fix broken sources.
